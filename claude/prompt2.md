My portfolio already has an established visual identity.

Inspect the existing `index.css`, global styles, design tokens and implemented sections before introducing any styling.

- Mobile-first, always.
- Normal/default letter spacing. No unnecessary tracking.
- `rounded-md` as the standard corner treatment.
- Thin 1px borders and separators.
- Hover effects limited to subtle changes in border, background or text color.

- Glass effect is essential.
- Smooth animations, with durations of at least 500ms.
- No emoji. Use the icon library already installed, such as Lucide React.
- Premium charcoal/black, champagne-gold and white/neutral color palette.
- Elegant typography and clear visual hierarchy.
- No excessive decoration.
- No generic dashboard appearance.

Use existing theme variables and reusable utilities wherever possible.

Do not create a separate visual identity for this section.

The Experience section should feel like a natural continuation of the Hero, About, Projects and Skills & Beyond sections.
